패션 쇼핑몰에서 상의 카테고리를 열면 많은 상품 중 일부가 첫 화면에 나옵니다. 기존에는 고객의 연령대와 관계없이 공통 인기 점수를 사용했습니다. 여기에 로그인한 고객의 연령대별 선호를 반영하는 경로를 추가했습니다. 검색어를 입력한 검색 결과와 베스트 목록은 이번 적용 대상에서 제외했습니다.

같은 카테고리라도 고객마다 순서가 달라질 수 있으므로 두 가지 준비가 필요했습니다. 상품에 연령대별 점수를 넣어 두고, 요청이 들어왔을 때 어떤 점수로 계산할지 선택하는 것입니다.

## 추천 점수는 상품을 색인할 때 준비합니다

고객이 카테고리를 열 때마다 외부 추천 데이터를 가져와 계산하면 요청 경로가 길어집니다. 그래서 배치에서 점수를 읽어 서비스의 연령대 구간으로 집계하고, 상품을 검색엔진에 색인할 때 함께 저장했습니다. 요청 시에는 OpenSearch가 상품 문서에 들어 있는 점수를 읽습니다.

원천 데이터는 5세 단위였고 서비스에서는 그보다 큰 구간을 사용했습니다. 두 구간을 합칠 때는 최근 7일의 조회수를 가중치로 사용했습니다. 예를 들어 다음과 같은 점수가 있다고 해보겠습니다.

```text
25~29세: 점수 0.8, 조회수 1,000
30~34세: 점수 0.4, 조회수    50

25~34세 점수 = (0.8 × 1,000 + 0.4 × 50) / 1,050 ≈ 0.78
```

단순 평균은 0.6이지만, 위 방식은 조회가 많았던 구간의 점수를 더 반영해 약 0.78이 됩니다. 조회수 합이 0이면 단순 평균을 사용했습니다. 이 계산만으로 추천 품질이 좋아졌다고 판단할 수는 없습니다. 많이 노출된 상품에 조회수도 쌓이므로, 기존 노출의 영향을 함께 받기 때문입니다.

집계한 점수의 캐시 유지 시간은 2시간으로 설정했습니다. 다만 원천 점수가 만들어지는 시각과 상품이 다시 색인되는 시각도 있어, 이 설정이 곧 화면 결과의 2시간 갱신 주기를 뜻하지는 않습니다.

## 요청에서 연령대에 맞는 계산을 선택합니다

연령대를 알 수 있으면 해당 필드와 개인화 계산 모드를 선택하고, 정보가 없으면 공통 점수를 사용합니다. 아래는 선택 부분만 단순화한 코드입니다.

```python
from typing import Optional

def age_settings(age_suffix: Optional[str]) -> dict:
    if age_suffix:
        return {"score_field": f"score_{age_suffix}", "use_per_age": True}
    return {"score_field": "score_global", "use_per_age": False}
```

실제 연령대 모드에서는 두 종류의 추천 점수를 더하고 기존 보조 점수와 섞습니다. 공통 모드에 있던 판매량·가격의 로그 곱 항은 빼는 분기도 추가했습니다. 추천 점수와 같은 정보를 중복해서 반영하지 않으려는 처리입니다. 점수순 정렬과 페이지 나누기는 유지했지만, `script_score` 안의 계산식까지 그대로인 변경은 아니었습니다.

두 점수를 더한다면 숫자의 범위도 살펴봐야 합니다. 예를 들어 한쪽은 0~1이고 다른 쪽은 0~100이라면, 그냥 더했을 때 두 번째 점수가 결과에 훨씬 크게 작용할 수 있습니다. 합산 코드 외에 원천 점수의 분포와 혼합 비율도 봐야 하는 이유입니다.

연령대 점수가 없는 상품은 해당 점수를 0으로 두고 나머지 값으로 비교했습니다. 목록에서 제외하지는 않습니다. 다른 보정값이 있으므로 연령대 점수가 0이라는 이유만으로 반드시 마지막에 오는 것도 아닙니다.

## 결과 캐시도 연령대를 구분해야 합니다

계산을 바꿔도 결과 캐시를 모든 고객이 공유하면 먼저 조회한 연령대의 목록이 다른 고객에게 보일 수 있습니다. 따라서 같은 카테고리라도 연령대에 따라 결과를 구분해야 합니다. 공통 결과 하나를 쓰던 때보다 캐시가 나뉘는 비용도 생깁니다.

이 작업에서는 연령대별 점수 입력과 계산 분기를 구현했습니다. 클릭률이나 구매 전환을 비교한 결과는 아직 없습니다. 품질을 평가할 때는 실제 개인화가 적용된 고객의 비중, 캐시 비용, 같은 상품의 반복 노출을 함께 확인해야 합니다. 구매 이력을 사용하는 추천은 [홈 재구매 추천](/posts/personalized-home-product-list/)에서 별도로 다룹니다.
