패션 쇼핑몰에서 상의 카테고리에 들어가면 많은 상품 중 일부를 첫 화면에 보여줘야 합니다. 기존에는 공통 인기 점수를 썼습니다. 여기에 로그인한 고객의 연령대별 선호를 반영하는 경로를 추가했습니다. 검색어가 있는 검색과 베스트 목록은 이번 개인화 적용 대상에서 제외했습니다.

변경 범위를 이해하려면 두 단계를 구분해야 합니다. 검색 결과를 점수순으로 정렬하고 페이지를 나누는 구조는 유지했지만, 그 점수를 만드는 `script_score` 공식에는 연령대 모드를 추가했습니다. “점수 필드만 바꾸고 계산은 전혀 바꾸지 않았다”는 설명으로는 실제 동작을 설명할 수 없습니다.

## 연령대별 추천 점수를 상품 문서에 준비했다

외부에서 계산한 추천 점수를 배치로 읽고, 서비스의 연령대 구간에 맞춰 집계한 뒤 캐시에 저장했습니다. 검색용 상품 문서를 색인할 때 이 값을 함께 넣었습니다. 따라서 고객 요청마다 외부 추천 데이터를 읽고 집계할 필요는 없습니다. 요청 때는 검색엔진이 이미 저장된 점수를 읽어 최종 점수를 계산합니다.

원천 점수는 5세 단위인데 서비스에서는 더 큰 구간을 사용했습니다. 같은 구간으로 합칠 때 최근 7일의 조회수를 가중치로 썼습니다. 아래 숫자는 집계 방식을 설명하기 위한 예입니다.

```text
25~29세: 점수 0.8, 조회수 1,000
30~34세: 점수 0.4, 조회수    50

25~34세 점수 = (0.8 × 1,000 + 0.4 × 50) / 1,050 ≈ 0.78
조회수 합이 0이면 단순 평균 사용
```

조회가 많았던 구간의 점수를 더 반영하는 정책입니다. 이 방식이 작은 표본의 흔들림을 줄일 수는 있지만, 조회수만으로 추천의 정확성을 증명하지는 못합니다. 기존 노출이 많은 상품에 무게가 더 실릴 수도 있습니다.

점수 캐시는 2시간 동안 유지하도록 설정했습니다. 캐시 만료, 원천 데이터의 생성 시각, 상품 색인 시각은 서로 다릅니다. 캐시 TTL만 보고 고객이 보는 추천도 2시간 안에 최신화된다고 단정할 수는 없습니다.

## 요청에서는 읽을 필드와 계산 모드를 정했다

연령대가 있으면 해당 구간의 필드를 선택하고, 없으면 공통 점수 경로를 사용했습니다. 아래는 필드명을 단순화한 설명용 코드입니다.

```python
from typing import Optional

def age_settings(age_suffix: Optional[str]) -> dict:
    if age_suffix:
        return {"score_field": f"score_{age_suffix}", "use_per_age": True}
    return {"score_field": "score_global", "use_per_age": False}
```

연령대 모드에서는 두 추천 소스의 구간별 점수를 더하고 기존 보조 점수와 혼합했습니다. 반면 공통 모드에 있던 판매량·가격의 로그 곱 항은 빼는 분기가 있었습니다. 추천 점수와 같은 신호를 중복 반영하지 않으려는 처리였습니다. 공통 배수나 고정 노출 상품 처리도 있으므로 이것을 단순한 “연령대 점수 내림차순”과 동일하게 볼 수는 없습니다.

두 소스의 점수를 더할 때는 숫자의 범위도 중요합니다. 예를 들어 한 소스가 0~1이고 다른 소스가 0~100이면 같은 비중으로 더해도 영향력은 다릅니다. 합산 코드만으로 원천 점수가 같은 척도로 정규화됐는지까지 확인할 수는 없습니다. 추천 품질을 평가할 때는 소스별 분포와 혼합 비율을 함께 봐야 합니다.

해당 연령대 점수가 없는 상품은 0으로 처리하고 나머지 점수로 비교했습니다. 목록에서 무조건 제외되지는 않습니다. 다른 보정값도 있으므로 반드시 최하위로 내려간다고 보장하지도 않습니다.

## 개인화 범위가 늘면 캐시와 측정도 달라진다

같은 카테고리라도 연령대별로 결과가 달라져 결과 캐시를 구분해야 합니다. 요청 수가 같다면 공통 결과 하나를 공유할 때보다 캐시가 분산될 수 있습니다. 생년 정보를 제공하지 않은 고객은 공통 경로에 남으므로, 전체 로그인 고객 수와 개인화가 실제 적용된 고객 수도 다릅니다.

이 작업에서 구현한 것은 연령대별 입력과 계산 분기입니다. 클릭률이나 구매 전환 개선을 비교한 결과는 확보하지 못했습니다. 후속 평가는 개인화 적용 비중과 캐시 비용, 같은 연령대 안에서 반복 노출되는 상품을 함께 보는 것이 필요합니다. 구매 이력을 쓰는 별도 경로는 [홈 재구매 추천](/posts/personalized-home-product-list/)에서 다룹니다.
